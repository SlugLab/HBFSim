# HBFSim：供审阅的迁移与 EQ 重规划摘要

本页整理 2026-09-08 已完成的迁移、关键审计、轻量检查与 EQ1–EQ4 重规划，供 `eval_base` 分支审阅。完整实验尚未运行，新增性能和物理可信性主张仍受门禁约束。详细阅读顺序见 [中文审阅指南](../../REVIEW_GUIDE.md)。

**迁移记录。** 工作区物理位置为 `/mnt/disk0/hbfsim-exp`，旧 `/root/hbfsim-exp` 为兼容链接。迁移记录显示全文件 checksum 无差异，77 项关键 SHA256、660 个 Git 仓库及环境/模型只读 smoke 通过；清理已验证源副本释放 131.912 GiB，清理时根盘可用 147.532 GiB。源隔离副本已删除；这组数值是迁移时采样，并非持续磁盘监控。[迁移报告](migration-report.md)和[摘要 manifest](migration-manifest.json)随包提供；完整源文件清单、全部 Git 逐仓库记录和模型仍在原主机。

**新方案。** EQ1 合并原机制与开销问题，增量等待采用 `ΔS=[L1−W]+−[L0−W]+`；EQ2 区分真正 off/shadow/active 与持续服务；EQ3 区分物理容量比和 HBM 内 KV/cache/staging 分配；EQ4 区分真实并发、dense 匹配和预取机制。当前矩阵 300 行（114/26/132/28），每行给出真实入口或明确 BLOCKED/INFEASIBLE，带配对、pilot 预算、门禁与停止条件。旧 2848 行/20485 次计划以原字节保存在历史目录。

**已有检查。** scalar emitter 的 19 项 CPU 检查、EQ3/4 的 27 项 CPU 检查、旧结果流水线 20 项检查、矩阵资源注册检查、增量等待三段算例及热 timeline 检查通过；迁移启动器 13 项 mock 检查通过。历史热证据 45 项引用 hash 与 20 项 golden 检查一致，2 个大型库 hash 按定向预算标记 DEFERRED。这些结果只覆盖对应工程或数值契约，不能替代 GPU 性能或实物 HBF 测量。

**仍需补齐。** 当前树尚缺 package thermal 实时集成、真正 off、实际刷新队列/完成/能耗、新分箱图导出、capacity/TMA 生命周期、独立 GPU/SASS 计时、物理拓扑映射、独立 staging/reservation 及 dense/live 对照；[后续补丁](../../minimal-followups.md)已拆出 20 个审阅范围。旧热反馈是受控 toy 参数/窗口结果，TRACE_COMPOSED 仅支持投影，OCP 规范本地 PDF 下载 403 导致其文件 hash 尚未归档。
