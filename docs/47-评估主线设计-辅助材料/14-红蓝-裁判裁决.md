## 二、三候选打分与 verdict

### C0(19 号规划)
- **判据一(可信度论证强度):纸面 4/5,可兑现 1/5。**机制/参数分离、差分公式、措辞门槛表、reference hierarchy、limitations 清单全对;但 EQ1 基础设施接近零(held-out 全仓库零命中 [一手,核查报告]),三条 A/B 路原样全堵,且从头到尾没说被验证的是哪个引擎。
- **判据二(基准化潜力):3/5。**benchmarking framework 要件清单(§1.2/§12)是三者中最全的,但无命名档案、无假设重演,相图是自设自答,读者引结论不引平台。
- **判据三(11 天可行性):1/5。**全文无一个天数,Gate 串行,无降级章节形态——不是排期。
- **记忆度(一行,不参与裁决):C0 无独立记忆点,D1 的「三介质五个数量级」已被证伪撤下,D2 的「把互相打架的已发表假设装进同一个被验过的框架重演」是三者中唯一真正的记忆点。**
- **Verdict:ADOPT_MODIFIED。**改法:不作为可执行计划,整体降为规范与方法供体——公平性契约(§1.2)、措辞门槛表(§6.8,数值保留、附 n 规则与注册时间戳)、差分公式(§5.2)、manifest/CSV(§12)、统计口径、Gate 0/1、§15.2 限制清单全部并入;其实验矩阵(EQ1 全网格、EQ3 相图、EQ4、§8.5 预取分层)不采纳;OCEAN 引用删除。

### D1(可信度最大化)
- **判据一:原文 3/5,修复后 4.5/5。**五环链条与留出纪律是最完整的可信度骨架;原文三处大伤(DRAM 腿断、全链押 E1.3、E2 未先除 time_scale 混杂)加模式留出的预定失败,修复后(两介质+域覆盖、第 0 天闸门、特征化集、F7)链条成立。
- **判据二:2/5。**基准化交付是 5 行文字且挂在唯一允许整体撤下的实验上。
- **判据三:2/5。**17.5 人天塞 8 天,排期不成立;但结构可缩。
- **Verdict:ADOPT_MODIFIED。**作为合并形态骨架(四实验链条、E1 基石、环结构、映射表纪律、Q6–Q14 处置)采纳;改:三介质主轴撤为两介质+域覆盖论证,E1.3 前提提为第 0 天闸门且 E3 出场资格解耦,模式测量改特征化集,E2 载体换 D2 的同适配器覆盖 3 档,E3 换 D2 假设重演,基准化交付升一等且独立于 E3 存亡,排期按第四节重排。

### D2(基准化最大化)
- **判据一:原文 2.5/5,修复后 3.5–4/5。**原文三处方法学硬伤:E3-c 模式间互证冒充验证、E1 撑不起 E3 等高线、删了唯一防 PR#3 类 bug 的 QD 配对;修复(F4、改名一致性检查、敏感性带、条件式句式)后可守。
- **判据二:5/5(设计)。**假设档案重演、以论文命名的器件档案、artifact 分箱,是三者中唯一回答「别人以后为什么绕不开我们」的设计,且社区痛点(tR 差 5 倍、带宽差 17 倍 [一手核实于 brief-1])客观存在。
- **判据三:2/5,修复后 3.5/5。**18 人天、旗舰主路无代码、回放备路测不了目标量;配置探针+第 2 天决断+换载体后可控。
- **Verdict:ADOPT_MODIFIED。**E3(命名档案+N×tR)、artifact 分箱、E2 覆盖 3 档载体并入合并形态;改:E3-c 降格改名、图 4 全标 projection+敏感性带+条件式且不裁决他人结论、档案按原文 4 KiB 重校验、E3-b 换容量轨迹回放载体标 trace-driven replay、补 F4、排期重排。

## 三、bet_the_paper

**敢。押的是第四节的合并主线 M,不是三个候选中的任何一个原样。**

直接理由三条:一,M 的每一级主张都有措辞档位和预写好的降级稿,最坏落点是一篇 Cylon 式的趋势级诚实论文——Cylon 全文没有一个百分比误差数字仍过了 FAST [一手核实于 brief-2 §1],这个底不是零;二,差异化主张(真实 GPU 执行中注入 + 真实专家路由)经 2026-03 以来撞车检索零命中 [一手核实于 brief-4],空位真实存在;三,全部三个致命级测量假象(time_scale、模式假验证、档案查表化)都已有第 0–2 天的廉价闸门,不是投稿前夜才暴露的形态。

两个会输的方式,如实写明、不折算成条件:其一,合作者 8 个执行日交付失败(第 5 天决断点触发全面降级,论文仍可投,但可信度章退为微基准+投影,竞争力明显下降);其二,CD8P 留出误差大到排序都不稳(按 C0 Gate 3 规则退到部件级标定主张,「基准」定位保不住)。这两个都是执行风险而非设计缺陷——设计层面我没有保留未说出的致命疑虑。押注唯一的前提性事实是:第 0 天四项闸门(epsilon 残余、backing 脚本、N 映射探针、time_scale 复测)必须真的在第 0–2 天执行完,这已写进主线本身,不是附加条件。
