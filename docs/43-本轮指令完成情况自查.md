### 术语表

下面这些词在后文反复出现，先一次性用平实的话解释清楚。

- **HBF（High Bandwidth Flash，高带宽闪存）**：一种把 NAND 闪存颗粒堆叠起来、与加速器（GPU 或 TPU）封装在同一个封装里的存储器件。NAND 闪存是固态硬盘里用的那种存储介质。
- **HBM（High Bandwidth Memory，高带宽内存）**：现在显卡上用的堆叠式内存，容量比 HBF 小、速度比 HBF 快。
- **HBFSim**：本项目要做的模拟器，用来在没有 HBF 实物的情况下预测程序跑在 HBF 上会是什么表现。模拟器指用软件模仿一种硬件的行为、输出时间与容量等指标的程序。
- **C1、C2、C3**：论文提出的三条挑战（challenge）的编号。C1 是拦截点问题，C2 是一次访问要花多久算不出来只能测出来，C3 是温度决定长期能跑到的速率。
- **D1、D2、D3**：论文给出的三条设计回应（design）的编号，与 C1、C2、C3 一一对应。
- **大纲文件**：`/root/hbfsim/HBFSim/docs/35-FAST27论文大纲与逻辑线.md`，写给导师和合作者读的论文大纲，是本轮最主要的交付物。同一份内容在 `/root/hbfsim/HBFSim/paper/35-FAST27论文大纲与逻辑线.md` 有一份同步副本，由 `/root/hbfsim/HBFSim/paper/Makefile` 的 `sync-docs` 目标生成。
- **submodule（子模块）**：一个 git 仓库里嵌套的另一个 git 仓库。本项目里 `/root/hbfsim/HBFSim/paper` 是投稿平台 Overleaf 的仓库，作为子模块嵌在 `/root/hbfsim/HBFSim` 里面。
- **PTX 与 SASS**：显卡程序的两种代码形式。PTX 是英伟达显卡的中间代码，还没有针对具体型号编译；SASS 是编译之后真正在显卡上执行的机器码。cubin 指只含已编译机器码、拿不到 PTX 的模块，遇到 cubin 就改不了代码。
- **NVBit**：英伟达官方出的一个工具，能在 SASS 这一层往显卡程序里插入额外代码。
- **OCP 规范**：开放计算项目（Open Compute Project）发布的 HBF 硬件规范，本项目用的版本是 v0.7.0，存在 `/root/hbfsim/HBFSim/docs/HBF_OCP/ocp2026-hbf-architecture-specification-v0-7-0.pdf`。
- **skill**：Claude Code 的一种可加载的指令包，加载之后它的内容进入当前这一轮的上下文。本项目常用的有 `systems-paper`、`academic-paper`、`verify-paper-sources` 三个。
- **hook（钩子）**：Claude Code 在某个事件发生时自动执行的一个脚本，例如用户提交提示词时、子代理启动时。
- **output style（输出风格）**：Claude Code 的一种配置，把一份文件的内容直接接进系统提示，使它对每一次回复都生效，不需要主 agent 自己想起来去读。
- **prose-writer**：一个专门负责写人读的文字的子代理，定义在 `/root/.claude/agents/prose-writer.md`。
- **ASK 与 TODO**：未决事项的两种编号。ASK 表示只有用户能拍板、不拍板就走不下去的事；TODO 表示主 agent 自己该做还没做的事。
- **vLLM**：一个大语言模型推理服务程序，本项目用它作为真实负载。
- **kernel 启动**：一次把一段程序交给显卡去执行的动作。本项目的覆盖判定就是在每一次 kernel 启动之前做一次。
