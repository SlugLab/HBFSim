# HBFSim v0.1.2 — Optimized Edition

This release provides the tested HBF inference optimizations, source code,
build instructions, configuration and compact performance data. The optional
OLMoE full147 setup uses nominal HBF delays; its validation scope and limits
are documented alongside the results. The existing UCIe interface and thermal model are unchanged.

The accepted strategy uses PTX input authentication caching, chunked host reads,
DSO digest caching and two configured canonical native-module declarations,
with the accepted agent/helper/pass combination. Persistent ELF caching and
same-page merging remain **off**. HBF simulation waits remain **nominal**, not
zero-injected. No memory-rewrite, helper or simulator algorithm is changed by
packaging this release. Default production execution is not silently switched
to this experimental setup.

These are **two different attempts**, one observation each, with the same fixed
prompt and two output tokens. Fifteen model/input/software cohort fields agree.
They are not a repeated-trial result, a single-factor causal speedup, or a
throughput guarantee for other workloads. The 26.55× accounting microbenchmark
is deliberately not used as an end-to-end speedup claim.

The current run naturally exited with code 0. Scoped acceptance covers exact
promised output tokens, 147 registered storages with representative modeled
address/service joins, 49 selected changed consumers plus 98 existing storages,
and 19 synchronized host timing regions with two calls each. Nine PTX modules
were inventoried; six had active modeled service. This does not prove that every
weight byte or all MoE experts were consumed, or constitute a new full-tensor
numerical comparison.

The original batch remains **FAILED** for a post-model consumer source-identity
pin. An isolated offline pin correction consumed the existing originals and
passed scoped validation and independent review; neither model nor collector
was rerun. Original ACK verification covers 199 files. Failure records and
unique raw data remain immutable with the authors; large raw logs, SHM images,
model weights, generated/vendor PTX and binaries are not redistributed.
